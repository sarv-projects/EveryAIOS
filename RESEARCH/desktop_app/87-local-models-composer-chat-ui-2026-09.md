## 3. Composer (main chat bar) — anatomy + conventions

**Per-surface one-liners:** AnythingLLM (expanding textarea + `/` slash + `@agent` trigger + paperclip + mic-web-only; model lives in workspace settings, NOT in-bar; attach-vs-RAG doctrine is best-in-class); Jan (bottom composer + `+` menu + reasoning-brain toggle; model at top dropdown — old split, prefer in-bar); Cherry (**customizable toolbar**, `+` panel, paste-long-as-file toggle, link chips; separate Chat/Agent composers; context-queue FIFO with pause/resume); Chatbox (in-bar model dropdown left + Search toggle + paperclip; Classic/Bubble; Prompt Library + quoting; most mobile-mature); Hermes (**model picker left-of-mic**, sticky-per-device + effort/fast presets + fuzzy match; up/down history; queue-editing; Quick Entry hotkey; HUD mini-composer; annotate-to-composer no-auto-send); opencode (build|plan badge + `>` prompt; **Tab cycles agents**, `@path/@alias`, `!shell`, `#lines`, `$EDITOR` compose, Readline keys; 20MiB/2000px/5MiB-b64 attach contract); Cowork (**Chat/Cowork/Code switch + 3-mode approvals + model dropdown + folder/repo pills ALL in-bar**; mid-turn correction without stopping); Zed (message editor + `+` context + model+provider picker + profiles + token meter; `@` files/symbols/threads/skills/diags/diffs/URLs; queued+Steer-toggle+Send-Now-double-enter); Cursor (mode picker + @-chips + model dropdown; Shift+Tab Agent/Ask/Plan/Debug; Plan→Build handoff); OpenClaw (22 typed slash commands Command|Directive|Inline + `/queue` 4 modes + `/goal` + footer agent/session/model/goal/think/tokens); OpenChamber (target/goal button + goal strip + Magic Prompts + `#snippets` + IME/CJK fix + draft preservation).

**10 conventions (3+ products converge — strong signals):** (1) Enter=send / Shift+Enter=newline (+ flippable setting; CJK-composition guard; Win-Terminal help). (2) In-bar model picker, sticky per-conversation (badge override-vs-default — Hermes billing trap proves the badge). (3) `@`=files/context, `/`=commands/skills (`#` diverges — pick ONE meaning). (4) Paperclip + drag-drop + paste chips (images PNG/JPEG/GIF/WebP; opencode's 20MiB/2000px/5MiB-b64 contract). (5) Stop + ordered queue + steer (pause/edit/delete/resume; Enter=queue, Cmd+Enter=now). (6) Up/Down history + per-topic drafts + $EDITOR/`paste-as-file` (no one does `Ctrl+R` — gap). (7) Thinking/effort + Fast presets beside model, per-model remembered. (8) Scope line in chrome (folder pill + ctx-meter + cost footer + goal strip). (9) Explicit Plan↔Build badge (never silent mode change). (10) Mic opt-in only, never default.

**Anti-patterns (never copy):** silent sticky override w/ divergent catalogs (Hermes #62055, real billing harm); Tab triple-duty (focus+complete+agent-cycle — opencode #13557/#20328); paste-path base64 blowup (opencode #38105 — default paste-as-text); approval modal without dropzone (opencode #31791); queue auto-fire before session-ready / sent-draft restore; Auto-mode hidden cost (Cowork burns extra — disclose); Skip bypassing delete (always typed-confirm); `#` double-meaning.

## 4. Thread/message UI — taxonomy + gaps

**L1 flat threads** (AnythingLLM workspace threads, Jan w/o project): fine <30 chats, fails on retrieval. **L2 Topics-in-Assistants** (Cherry Topics, Jan threads-in-projects, Chatbox threads-in-session): best balance, STEAL as default (pin, drag-drop, auto-name + manual-lock flag). **L3 Sessions+Workspaces** (Cherry Agent Sessions, Hermes profiles+sessions, Zed projects+worktrees): power/dev isolation (cwd/tools/memory). **L4 Tabs+Windows** (Hermes, opencode, Zed sidebar): parallel runs (Ctrl+Tab, reopen-closed, per-tab model). Plus Archive/History split (Zed/Hermes/Cursor) — Delete explicit + trash, never hover-X. **Recommendation: L2 default + L3 on demand + L4 tabs.**

**Message-action union:** user (Copy, Edit-resubmit-truncate, Delete, Quote/Reply, Pin, Branch/Fork, Copy-as-MD, Speak, Translate, Share, Export, Multi-select); assistant (Copy, Copy-code, Regenerate-same, Regenerate-with-model, Edit-correction-no-resubmit, Branch-from-here, Feedback+detail, TTS, Translate, Export MD/Word/PNG, Open-as-Markdown, Add-to-notes, Cite-jump, Preview, Checkpoint-revert, Hunk Keep/Reject, Stop, Continue, Send-now/Steer). Conventions: edit-resubmit=truncate-below; regenerate=same-history (pager beats replace); reasoning=collapsible+live-timer; tools=grouped pills; compaction=auto-summary+expander (`Context Compacted`, `SDKCompactBoundary`); titles=auto+manual-lock; export floor=Markdown, ceiling=Cherry (Word/PNG/Obsidian/Notion); citations=RAG-footnotes `[^1]` vs search-cards (no one does both well).

**5 transcript gaps in a typical Tauri cockpit:** (1) no timeline rail + Find-in-page + jump; (2) no checkpoint/restore + Last-turn diff + compaction expander; (3) no queue/steer/send-now; (4) no citations-footnotes + artifact gallery + preview rail; (5) no durable per-turn meta (durations/model/tokens/cost/timestamps — timestamps missing everywhere, easy win).
